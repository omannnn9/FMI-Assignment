B. FUNCTION PARAGRAPH STRUCTURE (Use this for each function)

1. DEFINE the function
E.g., Liquidity provision refers to…
2. EXPLAIN why this function is important
Describe the role the function plays in any forex market.
3. ANALYSE how the function works (cause–effect)
Example:

When tourist inflows rise, supply of EUR increases → MUR appreciates.
When importers demand USD for fuel, USD/MUR rises.

4. APPLY to Mauritius (REAL EXAMPLES)
Use specific, local, realistic examples:

Tourism converting EUR/GBP
Textile/seafood exports converting USD
Fuel and pharmaceutical imports
Banks like MCB, SBM, AfrAsia coordinating FX trades
Bank of Mauritius interventions

5. EVALUATE (Discuss effectiveness/limitations)
This is where your high‑mark critical thinking shows.
Example evaluation points:

Mauritius faces periodic USD shortages.
BoM interventions sometimes distort free‑market price discovery.
Businesses complain about delays in obtaining FX from banks.
Hedging is limited because Mauritian firms lack derivatives expertise.

6. LINK BACK to the question
One sentence connecting the function to the “role of the forex market”.
